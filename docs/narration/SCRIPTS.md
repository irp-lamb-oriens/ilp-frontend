# ILP landing narration scripts (for ElevenLabs)

Each clip is a short pitch for its section, one or two sentences. The page itself carries the detail; the voice says why the section matters.

How to generate the audio

- Generate one clip per block below, using the file name given, and paste only the text under "Read:".
- Prices are spelled out the way they should be spoken.
- Suggested voice settings: one calm, warm voice for all three pages, stability around 50%, similarity around 75%, style low, speed 1.0.
- Upload the finished files to `frontend/public/narration/<page>/<file name>`.
- On the home page the narrator plays home-05 before home-04, because "What you get" sits above the costs section on the page.

Pronunciation: Colegio "co-LEH-hee-oh".
